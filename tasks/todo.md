- [ ] Public site and brand integration; responsive navigation and all public links work.
- [ ] Guest intake stores an assessment, lead, consent and durable confirmation transactionally.
- [ ] Auth and applicant account use verified identity and enforce ownership.
- [ ] Staff MFA and scoped lead management enforce authorization on server and database.
- [ ] Notification worker retries safely and tracks delivery.
- [ ] Unit, browser, database permission checks, typecheck, lint and build verified.
- [ ] Docker build/runtime verified; setup, limitations and GitHub handoff documented.
