# Account, consultation and notification update

The main navigation now uses Start consultation before the account entry, with a visible sign-in link. Visitors are redirected to registration before consultation intake. Email verification and a matching account email are enforced by the intake API. The WhatsApp contact button is smaller.

The home page includes the two requested presidential portraits with factual context and official source links. Unverified quotations and statistics from the screenshots were omitted. Pexels photographs were added to about, services, process, pathways and contact pages. Native scrolling now includes reversible section movement, layered photographic motion and the flight-path progression. Text keeps full contrast throughout, and reduced motion shows complete static content.

The owner explicitly replaced mandatory staff TOTP with verified email/password and administrator-assigned roles. The main admin account was created in hosted Supabase using the requested credentials. The password is not in source control. Only active administrators can assign staff roles or configure admin email recipients; the last active administrator cannot be demoted. Every role/recipient change is audited.

Nine migrations were applied to hosted Supabase. Notification recipient configuration was applied privately; new environments start with empty recipients. Real account notifications have recipient isolation, read state, safe internal links and publication idempotency. Avatar uploads are bounded, decoded to WebP, metadata-stripped and stored privately in owner folders.

The Green API instance and requested group were verified through read-only API calls. The local Docker scheduler processes durable event alerts for verified registrations, consultation requests and lead changes. No group test message was sent. Resend accepted the authorized setup email to its account owner. The test sender is restricted to that owner until domain verification; the domain was added but DNS work was deferred. Provider acceptance is distinct from inbox delivery.

Validation: strict typecheck, lint and 33 unit checks passed. All nine migrations plus adversarial identity, role, ownership, read state, avatar, last-administrator and event-lease checks passed on disposable PostgreSQL. All 13 browser checks passed against Docker, including six-language persistence, Arabic RTL, registration gating, phone layouts, keyboard controls, reduced motion and axe checks. The real admin dashboard opened without an authenticator challenge.

The full audit reports the unpatched development-tool advisory [GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf). The production dependency audit reported zero findings. The CI full-audit gate remains in place. A fresh independent review initially found two UI lifecycle/cascade defects; both were corrected. A later delegated review could not run because the reviewer reached its usage limit, so no independent final approval is claimed.

The original live website and DNS remain unchanged. Public intake remains off until Turnstile, Supabase Auth email configuration and the remaining launch requirements are complete. Detailed forms and service/legal pages are still English, with language-support notices. The bell shows the 20 most recent messages and an exact overall unread count; a paginated archive is a later improvement.
